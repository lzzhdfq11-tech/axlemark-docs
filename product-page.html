Product page

The Axlemark product page is built for parts: a fit check against the shopper’s saved vehicle or device, SKU and part number, specifications tables from metafields and every Shopify buying option. The product template has two sections: Product information, which holds the gallery and all product blocks, and Related products. This page explains every block, plus the product card and tax label options.

Default layout

The default product template shows these blocks in this order. Drag blocks to reorder them, hide the ones you do not need, and add app blocks where your apps provide them.

  1. Vendor
  2. Title
  3. SKU and part number
  4. Product rating
  5. Price
  6. Fitment check
  7. Variant picker
  8. Inventory status
  9. Quantity selector
  10. Buy buttons

Also available: Text, Custom Liquid and Pop-up.

Variant picker max 1

One control per product option, as buttons or a dropdown. Sold-out and unavailable combinations are marked. Swatches: for options that have colors or images set on their option values in your admin, buttons become circle or square swatches. Combined listings are supported: option values that belong to another product link to it.

Quantity selector max 1

Minus and plus buttons with a number field. Respects quantity rules (minimum, maximum and increment) when you use them.

No settings.

Buy buttons max 1

Add to cart plus, optionally, accelerated checkout buttons (the wallets your store and the customer can use). Errors such as “not enough stock” appear inline.

  • Subscriptions: when a product has selling plans from a subscription app, purchase options (one-time or subscription) appear above the button automatically.
  • Gift cards: with Show recipient form for gift cards on, gift card products show a “send as a gift” checkbox with recipient email, name, message and send date.

Pickup availability max 1

Shows “Pickup available at …” and a dialog listing every pickup location for the selected variant. Nothing shows until local pickup is set up for a location in Settings → Shipping and delivery.

Editor note: Shows local pickup availability when pickup is set up for a location in your Shopify admin.

Inventory status max 1

Real stock status for variants whose inventory Shopify tracks: In stock, Low stock (with Theme settings → Inventory → Show low stock message and its threshold), Out of stock, or “Out of stock, available to order” when you allow overselling.

Editor note: Uses real inventory only. Set the low stock message in Theme settings → Inventory.

Description max 1

The full product description.

Collapsible tab

An accordion row for details such as warranty, shipping, fitting instructions or compatible models. Content can come from three places, shown in this order:

  • Tab content: type text, or select the dynamic source (database) icon to connect a product metafield, for example custom.warranty. Each product then shows its own text.
  • Tab content from page: reuse a page, for example your shipping policy page, on every product.

The heading falls back to the page title when left empty. Add as many tabs as you need.

Specifications table formats

Create a product metafield definition in Settings → Custom data → Products, for example namespace and key custom.specs, and enter the same key in the Specifications table block. These metafield types are supported:

JSON: an object

{
  "Width": "205 mm",
  "Material": "Ceramic",
  "Position": "Front axle"
}

JSON: a list of objects

label and value (or name / key instead of label). A list of pairs such as [["Width", "205 mm"]] also works.

[
  { "label": "Width", "value": "205 mm" },
  { "label": "Material", "value": "Ceramic" }
]

Multi-line text (or a list of single-line text)

One Label: value per line.

Width: 205 mm
Material: Ceramic
Position: Front axle

Rich text or any other type

Rendered as is, so you can paste a formatted table or list.

Tip

Add one Specifications table block per metafield if you keep several, for example dimensions and electrical data. Each block has its own heading.

Collapsible tabs with dynamic sources

  1. Create a product metafield definition, for example Warranty (custom.warranty, rich text or multi-line text).
  2. Fill it in on each product.
  3. In the theme editor, select a Collapsible tab block, then the dynamic source icon next to Tab content, and choose the metafield.

Use Tab content from page for text that is the same on every product, such as shipping and returns.

  • Status badges from tags: one rule per line, tag | label or tag | label | icon. For example fitting-kit | Fitting kit included | wrench or new-arrival | New | tag. The first rule that matches a product tag is shown on the card.
  • Unit label metafield: create a single line text product metafield such as custom.unit_label, fill in values like “per set” or “per pair”, and enter the key here. The label is shown after the price.
  • Shipping notes from tags: one rule per line, tag | text, for example ships-today | Ships today or freight | Freight item, ships separately. The first match is shown with a truck icon.
  • Button: Quick add, or choose options (default) adds single-variant products to the cart and links products with options to their page; Quick add only shows a button only on single-variant products; Link to product page shows a button with your own label, for example “View and buy”, on every card.
  • Swatches: when a product option has colors or images set on its option values, the card shows up to five swatches with a “+N more” count.
  • Ratings: read from the standard product rating metafield that review apps fill in.

Tax label and tax switch

Stores that sell to both consumers and businesses can label prices with the tax treatment. Open Theme settings → Tax display, then turn on Theme settings → Product cards → Show tax label after prices. Checkout always calculates the actual tax.

Editor note: Adds a small tax label after product card prices. Checkout always calculates the actual tax.

SettingTypeDefaultOptions and notes
Tax labelSelectNoneNone / Prices include tax / Prices exclude tax / Let customers switch.
Included labelText“incl. tax”
Excluded labelText“excl. tax”
Tax rate (%) for the switchNumber10Only used by "Let customers switch" to estimate the other price. Add the switch to a page with a Custom Liquid section: {% render 'tax-note', toggle: true %}. The quick order section shows it automatically.
  • Prices include tax or Prices exclude tax prints the matching label after card prices.
  • Let customers switch adds an incl./excl. switch. Card prices are converted with the Tax rate setting, so the other price is an estimate, and the shopper’s choice is remembered on their device. The quick order page shows the switch automatically; on other pages add it with a Custom Liquid section containing {% render 'tax-note', toggle: true %}.
