Getting started

Set up Axlemark in about an hour: install the theme, pick a preset, build your menus and brand, then set up the product finder.

1. Install the theme

  1. Open the Axlemark listing on the Shopify Theme Store while logged in to your store.
  2. Choose a preset (Axlemark or Signal) and select Try theme. Shopify adds an unpublished copy to Online Store → Themes.
  3. Select Customize to open the theme editor. Your live store does not change until you publish.
  4. Buy the theme from the theme library when you are ready, then publish it.
Moving from another theme?

Products, collections, pages, menus and metafields stay in your store. Only theme settings and section content need to be set up again.

3. Set up menus

Create menus in Content → Menus (on older admins: Online Store → Navigation).

Main menu (mega menu)

The header uses the menu with the handle main-menu by default (Header → Main menu). Build it in three levels:

Brakes                 ← level 1: top-level item in the menu bar
  Brake pads           ← level 2: column heading in the mega menu panel
    Front brake pads   ← level 3: links under the heading
    Rear brake pads
  Brake discs
    Vented discs
Filters
  Oil filters
  Air filters
  • Top-level items with children open a full-width panel on desktop. Items without children are plain links.
  • On mobile and tablet the same menu opens in a drawer, one level per panel, with a back button.
  • Open menu on hover (Header) opens panels on mouse hover; keyboard users always open them with Enter or Space.
  • Add a Mega menu promotion block to the Header and enter a top-level item’s title (for example Brakes) in Menu item to show an image tile in that panel. Up to 12 promotions.
  • Secondary menu (optional) shows utility links such as Help or Track order next to the main menu.

Footer menus

Add a Menu block to the Footer for each column. The default menu is footer. Footer menus show top-level items only, so keep them flat. The block heading defaults to the menu title.

Customer account menu

The account icon shows links from the Customer account menu setting (default customer-account-main-menu).

4. Logo and favicon

  • Header → Logo image, with separate Logo width on desktop (60–300px) and Logo width on mobile (40–200px). Without a logo, the store name is shown.
  • Use logo as the home page heading: turn on only if no home page section uses an H1. The Hero heading is an H1 by default.
  • Also upload your logo in Settings → Brand. The theme uses that logo in search engine structured data.
  • Theme settings → Favicon: a square image, displayed at 32 × 32px.

The Header also has a Menu color scheme for the menu bar, mega menu panels and the mobile menu, and the Hero has a separate Finder color scheme for its finder card.

6. Typography

  • Headings: Font, Font size scale (80–140%) and Letter case (Default or Uppercase).
  • Body: Font and Font size scale (90–130%).

Fonts come from Shopify’s font library and are served by Shopify, so they need no external services. System fonts load fastest.

7. Layout and product cards

  • Layout: Page width (1000–1800px), Space between sections, Buttons and inputs corner radius, Cards corner radius, and Reveal sections on scroll (off by default; never animates for shoppers who prefer reduced motion).
  • Product cards: Image ratio, Image fit (Fit or Fill), Show vendor, Show SKU, Show product rating, Show second image on hover, Enable quick add and the Sale badge style (Sale, Percentage off or Amount off). Extra card details (status badges and shipping notes from tags, a unit label, the card button and a tax label) are explained in Product cards.

Quick add shows an Add to cart button on cards for products with a single variant. Products with options show Choose options, which opens the product page.

9. Set up the product finder

  1. In Theme settings → Product finder, check What shoppers select (for example vehicle) and the level labels. Leave the third level blank for two levels.
  2. Add your list: Finder entry blocks in the Product finder section for small lists, or a JSON file in Finder data file URL for large ones.
  3. Tag your products with the matching tags, for example model-a1, and add the universal tag to products that fit everything.
  4. Add the Fitment check block to your product template (it is included by default).

The full guide, with JSON examples, is on the product finder page.

10. Store details, search and inventory

  • Store details: customer service phone, email and hours, plus your business type. These feed the footer Contact details block and structured data. See SEO.
  • Social media: add your profile links. They appear in the footer, the announcement bar (optional) and structured data.
  • Search behavior: search suggestions show products, collections, pages, articles and suggested queries as shoppers type.
  • Inventory: Show low stock message with a threshold (1–20) uses your real inventory levels only.
  • Currency format: Show currency codes on storefront prices. Cart and checkout always show them.

11. Publish checklist

  • Logo, favicon and Settings → Brand logo uploaded.
  • Main menu has three levels where needed; footer menus are set.
  • Color schemes checked for contrast; fonts chosen.
  • Product finder labels set, data added and a few products tagged; tested on desktop and mobile.
  • The finder collection template has the Finder results intro section.
  • Product template blocks reviewed: specifications metafield, collapsible tabs and Fitment check.
  • Theme settings → Store details filled in; social links added.
  • Home page FAQ answers are real and accurate; Testimonials contain only real customer feedback.
  • Cart type chosen; a test order placed with a test payment method.
  • Policies added in Settings → Policies (linked from the footer).
  • Preview checked on a phone, with a keyboard, and in a second browser.
  • Theme published from Online Store → Themes.
