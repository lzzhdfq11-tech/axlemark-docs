Frequently asked questions

Short answers to the questions merchants ask most about Axlemark. For step-by-step setup, see Getting started and the product finder guide.

Questions

Which stores is Axlemark designed for?

Axlemark is a Shopify theme for large-catalog parts and accessories stores, with presets for auto parts (Axlemark) and tech, electronics and IT accessories (Signal). Stores with large catalogs where compatibility matters: auto parts and accessories, tech and electronics accessories, tires and other size-based products. It works for any store with deep categories and many SKUs.

What is the difference between the Axlemark and Signal presets?

Axlemark is set up for auto parts with a Make / Model / Year finder and a "vehicle" wording. Signal is set up for tech accessories with a Brand / Device finder and a "device" wording, rounder corners and a different heading font. Both include the same sections and settings.

Can I switch presets later?

Presets only set starting values. You can change colors, fonts, finder labels and sections at any time without switching. To start fresh with the other preset, add the theme again from the Theme Store with that preset; it is added as a separate unpublished theme.

Do I need an app for the product finder?

No. The finder is built into the theme. It uses product tags plus a list you add in a section or as a JSON file in Content → Files.

How many vehicles or devices can the finder handle?

Section blocks suit a few dozen first-level entries. For thousands of entries, use a JSON data file uploaded to Content → Files. The finder supports up to three levels.

How do I tell the theme which products fit which vehicle?

Add the entry's tag to the product, for example model-a1. A parent tag such as make-a fits every model of that make. Products with the universal fit tag show "Universal fit".

Will the fitment check ever say a product fits when it does not?

The check only says "Fits your..." when the product carries the selected tag or a parent tag. Otherwise it shows a neutral "Check compatibility" or "Not confirmed" message. Accurate tags are your responsibility, so review them when you add products.

Can I use metafields instead of tags for fitment?

The finder and fit check use tags, because Shopify can filter collections by tag without an app. You can still show detailed compatibility from a metafield in a Specifications table or Collapsible tab block.

How do I set up the mega menu?

Create a main menu with three levels in Content → Menus: top-level items, column headings and links. The header turns items with children into full-width panels. Add Mega menu promotion blocks in the Header for image tiles.

How do I add product filters?

Filters come from Shopify's Search & Discovery app. Install it, add filters such as availability, price, vendor, product type or metafields, and they appear on collection and search pages automatically.

Can shoppers add to cart from collection pages?

Yes. With Enable quick add on (Theme settings → Product cards), single-variant products show Add to cart on their cards. Products with options show Choose options, which opens the product page.

Can I use a cart page instead of the cart drawer?

Yes. Go to Theme settings → Cart → Cart type and choose Page. Shoppers then go to the cart page after adding a product.

How do I show a specifications table?

Create a product metafield such as custom.specs (JSON or multi-line text with "Label: value" lines), fill it in, and add the Specifications table block to the product page with that key.

Does Axlemark support subscriptions, gift cards and local pickup?

Yes. Purchase options appear automatically for products with selling plans from a subscription app. Gift card products can show a recipient form. Pickup availability shows once local pickup is set up for a location.

Does the theme add structured data for search engines?

Yes: store, website with search, breadcrumbs, products, articles and FAQs. If an app already adds this, turn off Add structured data in Theme settings → Store details to avoid duplicates.

Does the theme work with review apps?

Yes. Product cards and the Product rating block show ratings that review apps save in the standard product rating metafield. App blocks can also be added to the product page.

Is the theme translated and multi-currency ready?

Yes. Axlemark comes in 16 languages for the storefront and the theme editor: English, German, French, Spanish, Italian, Dutch, Portuguese (Portugal), Danish, Swedish, Polish, Czech, Finnish, Norwegian Bokmål, Japanese, Korean and Simplified Chinese. You can edit any text in Online Store → Themes → Edit default theme content. Country/region and language selectors appear in the header and footer when you sell in several markets or languages.

Does Axlemark load external fonts or scripts?

No. Fonts come from Shopify's font library and the theme loads no external scripts or tracking. Apps you install may add their own.

Can the finder be used for printers, ink and toner?

Yes. The finder works for anything that fits a specific model. Set the level labels to Brand, Series and Model, set What shoppers select to printer, and tag each cartridge or toner with the models it fits. Shoppers then see "My printer" in the header and "Fits your printer" on product pages. The same setup works for laptops, tablets and other devices.

How does the size finder work for tires?

Add the Size finder section, choose the collection with your tires and enter a tag pattern such as tyre-{1}-{2}-r{3}. The section reads tags like tyre-205-55-r16 from that collection and builds Width, Profile and Rim dropdowns that only offer sizes you stock. Popular size blocks add one-click chips. No data file is needed.

What is the shop-by-part vehicle diagram?

It is an interactive drawing of a hatchback, sedan, SUV or pickup, with exterior and interior views. You add up to 12 hotspots, each with a part name, short text and a collection or links. Shoppers select a hotspot to shop that part. Use it in the Shop by part section or in the right column of the Split hero.

Which header layout should I choose?

Mega menu bar shows every top-level menu item with its own full-width panel and suits menus with a handful of top-level items. Categories button and link bar suits very large catalogs: one Categories button opens a catalog menu with category images, and a second row shows quick links such as top categories or deals. Both use the menu drawer on mobile.

Can business customers order many parts at once by SKU?

Yes. Create a page, assign the quick-order template and link it from your menu. Shoppers type or paste part numbers (SKU or barcode) with quantities, see each match live and add everything to the cart in one step. It uses your store search, so no app is needed.

Can I accept trade or wholesale account applications?

Yes. Create a page with the trade template. The form asks for business details and is sent through Shopify's contact form to your store email. After reviewing it, you set up the customer in your admin, for example with a customer tag or a B2B company.

How do buying guides show the products they mention?

Blog posts show a Products in this guide row. Fill in the article's product list metafield custom.related_products, or give the article a tag that matches a collection handle, and the products appear below the post. The article template also shows related posts from the same blog.

Does Axlemark help with AI assistants and AI search (GEO)?

It gives AI assistants and search engines clear, readable data: store, website search, breadcrumb, product and article structured data, FAQPage data from FAQ sections, buying guides linked to products, an A-Z brand directory and specifications tables in plain HTML. The quality of your own product data matters most; see the SEO and GEO guide for recommended practices.

How do I get help?

Check this documentation first, then contact Axlemark theme support through the support form. We reply within 2 business days.
